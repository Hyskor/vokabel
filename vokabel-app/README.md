# Greenwich Vocab

Kleine Lern-App für die Vokabeln aus **Pick-up A: We're from Greenwich** (S. 184).

## Starten

```bash
cd vokabel-app
npm install
npm run dev
```

Dann im Browser die angezeigte Adresse öffnen (meist `http://localhost:5173`).

## Lernmodi

1. **Karteikarten** – Deutsch → Englisch umdrehen, Aussprache anhören  
2. **Quiz** – Multiple Choice (Deutsch → Englisch)  
3. **Tippen** – Englische Antwort selbst schreiben  

Aussprache nutzt die eingebaute Browser-Sprachausgabe (am besten mit Chrome/Edge und englischer Stimme).
